# 验证记录

## 1.0.8

Windows x64 安装包通过静态检查、生产构建、原生自检和 14 项文件夹夹具集成检查。最终打包程序通过 49 个窗口场景，其中 11 项覆盖任务进度的深浅主题、窄窗口、零值、未知总量、减少动态效果、等待、取消、失败和完成状态。进度状态通过合成任务事件验证，界面未记录渲染错误。

1.0.7 的单盘扫描入口已验证键盘选择、盘符与卷标显示、磁盘断开、未就绪、空列表和窄窗口。界面测试使用替代的磁盘列表与扫描请求接收器，文件扫描引擎另以真实文件夹夹具验证。1.0.6 的两个复制路径入口验证成功反馈、重复点击计时和失败恢复，剪贴板使用内存替身。

已授权的持续快扫会话、取消及退出流程通过协议测试，真实管理员会话的完整复测仍待完成。优化后的物理整盘扫描耗时尚未更新。安装包未签名，安装器源文件与已验证的安装、升级、卸载和回滚版本一致。

## 1.0.5 及以前

1.0.5 检查空间分析、历史、重复文件、清理、操作记录、后台任务、设置及相关弹窗。去除重复统计口径、分组含义、常规完成状态和功能介绍，合并导出与文件操作入口。无选中项时树图使用完整宽度，短预览清单按实际项目数收缩。缓存清理影响集中显示于预览确认，原生回归检查验证影响说明仍包含在执行清单中。界面审阅包含空状态、重复组、扫描差异、清理规则、操作预览、类型与导出弹窗，以及窄窗口。

1.0.4 修正树图提示框的固定定位和残留。提示在指针停留 350 ms 后出现，靠窗口边缘时换向，宽度上限为 360 个逻辑像素。移动、离开、点击、Esc、失焦、滚动、缩放或视图更新会清理提示及计时器。覆盖两种布局、深浅主题和窄窗口，检查提示边界、指针避让、事件穿透与关闭后的延迟重现。

1.0.3 使用同一份 594,823 文件的磁盘记录做普通权限对照。概览读取从 4,338／5,327 ms 降至 768／710 ms，目录树为 24／3 ms，树图为 185／171 ms。全盘和目录范围的总量、文件类型统计与旧版逐项一致。界面直接显示快照已有总量，类型与树图分别加载。

MFT 读取改为复用缓冲区并原地解析记录，减少流信息、路径和名称去重的分配。有效分配位图用于跳过空区间，扫描结束会重新读取位图并补读新增占用区间，位图不可用时读取完整文件表。普通权限样本验证覆盖解析后缓冲区复用、位图区间、扫描期间分配变化、无效映射回退和空记录的分配开销。本轮遵照用户要求使用无需提权的验证，优化后的真实整盘读取耗时待复测。

1.0.2 将管理员授权前移到应用启动。新增回归覆盖取消授权后避免重复弹窗、显式重试、同一会话处理多个卷及控制管道关闭后退出。启动请求已实际触发 Windows UAC，持续授权会话的真实扫描、取消及退出仍待完整复测。

1.0.1 修正设置页滚动容器的限宽，页面恢复填满工作区，滚动条位于右侧边缘。检查了 1440×940 和 920×680 逻辑尺寸、200% DPI、深浅主题及底部滚动，页面与工作区右边界一致，未出现横向溢出。其他功能页已使用同一全宽容器。安装器源文件与 1.0.0 一致，本次复用其安装、升级和取消回滚验证，另行核对新包版本、来源与界面。

## 2026-11-03

Windows 11 x64 上完成 TypeScript 检查、ESLint、前端生产构建、.NET 自包含构建和原生自检。14 项集成检查通过，覆盖扫描汇总、层级表格、树图、硬链接、筛选、重复文件保护、预览后变化拒绝、重命名刷新、历史差异、跨盘移动、根目录保护、导入导出、自定义规则和保存后重开。

开发模式与最终打包 EXE 的 Electron 渲染检查覆盖深浅主题、两种布局、920×680 和 1440×940 逻辑尺寸、200% DPI、键盘行导航、键盘调列宽及列设置对话框，未记录渲染错误。截图使用合成文件。托盘自绘菜单、无响应时释放等待和恢复打开检查通过。系统截图接口在该会话返回 Direct3D 捕获错误，原生鼠标和多显示器交互仍需补充验收。

将先前真实 MFT 扫描与 Windows 当前文件元数据抽样对照，E 盘 998 项、D 盘 881 项未发现文件身份或分配空间差异。E 盘另外 6 项已变化、1 项不可读，D 盘另外 118 项已变化、3 项不可读，均排除在可比样本之外。缓存发现检查识别了 Windows、Chrome/Edge、pnpm、pip、uv、NuGet 和 Pub 对应位置。

## 扫描性能

优化后先构建内存分析结果，再后台保存 SQLite 历史。最终 E 盘实测读取 80,391 个文件、4,628 个文件夹，读取约 1,208 ms，汇总 63 ms，结果可查询共 1,271 ms。后台保存约 1,430 ms，UAC 等待单独记录。统计占用 698,996,711,424 字节，扫描完整且没有问题项。

缓存元数据基准包含 589,890 个文件，内存汇总 631 ms。首次文件排行排序约 1,107 ms，名称筛选 195 ms，类型筛选 170 ms。该基准从已有数据库加载数据，不能代替物理全盘扫描测速。

加入 NTFS 系统记录后，修复坏簇映射把整卷逻辑范围计入占用的问题，回归覆盖空洞和混合已分配区间。MFT 记录结构与数据区间依据 Microsoft 文档处理。[MFT](https://learn.microsoft.com/en-us/windows/win32/devnotes/master-file-table) · [属性记录](https://learn.microsoft.com/en-us/windows/win32/devnotes/attribute-record-header)

最终系统记录修复已通过用户手动确认 UAC 后的真实扫描。权限取消回退另有验证，权限等待时间从实际扫描时间中分离。

旧测试实例曾出现主窗口白屏与托盘无响应。正常启动与截图检查现统一使用软件绘制，主窗口恢复显示真实 E 盘结果。托盘自绘菜单超时后使用 Windows 原生菜单，退出检查界面状态超过 3 秒时转为原生确认，再执行后台保存与收尾。
