# 使用说明

## 空间分析

应用启动时请求一次 Windows 管理员授权，由用户确认。已授权的快扫进程供本次运行期间复用，退出应用时一同关闭。取消授权后可继续普通扫描，或点击“重新授权”。

在顶部选择盘符并点击“扫描”，每次扫描一个本地磁盘或外接盘。首次打开时也可点击磁盘卡片开始扫描。NTFS 自动使用快速扫描，其他文件系统和权限回退使用目录遍历。展开磁盘菜单会更新磁盘列表。扫描过程中可以取消，受访问限制的内容会列为问题。

默认按实际占用展示，切换统计口径后，排序、占比和树图使用相同口径。硬链接共享的分配空间计一次。目录表格支持展开、排序、选择显示列及拖动列宽，文件排行支持名称、类型、大小和时间筛选。单击项目查看详情，双击目录深入查看，顶部可返回上级或整个扫描范围。

两种布局共用当前数据与选择。树图颜色对应文件扩展名，目录标题表示层级。底部显示选择合计与扫描分段计时，后台保存状态独立显示。磁盘已用空间与文件分配空间之间的差额可能来自文件系统元数据、访问限制和扫描期间的变化。

## 文件操作

先选择项目，再生成操作清单。检查路径、预估空间和警告后确认执行。普通删除移入回收站，永久删除有独立入口。移动或重命名后会刷新受影响区域。执行记录保留成功、跳过、失败与取消结果，重试前重新分析当前文件。

磁盘根对象、系统关键目录、NTFS 元数据和应用资料受到保护。文件在预览后发生变化时，操作会拒绝该项目。跨盘移动先复制并校验，再移除源文件。云盘目录的删除和移动会提示同步影响。

## 重复文件与清理

重复文件按大小筛选候选，再读取内容进行校验。可以设置优先保留目录，确认建议后批量选择。每组至少保留一份，硬链接单独识别。在线文件默认跳过，主动选择下载校验时显示预计下载量。

缓存整理包含 Windows 临时文件、Chrome/Edge 和常用开发工具。下载缓存、工具支持的未使用包修剪、全部共享依赖清空分开呈现。共享依赖清空需要单独确认，后续项目可能需要恢复依赖。

自定义规则支持目录、名称或扩展名、大小、修改时间和排除项。规则生成待确认清单，沿用文件操作保护。

## 历史与导出

完整扫描自动保存文件级记录。默认每个范围保留最近 10 次，历史容量上限为 2 GiB，可在设置中调整。固定记录参与容量计算。容量不足且无法淘汰时，界面提示处理。

选择两次历史记录查看目录和文件差异。可识别的移动与重命名依赖文件系统身份信息。历史记录与当前文件可能已经不同，修改文件前应重新扫描。

导出菜单提供 CSV 明细、完整扫描快照和树图 PNG。可选择当前筛选范围或完整结果。导入快照可用于分析，执行文件操作前需重新扫描本机位置。
